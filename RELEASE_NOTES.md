Minecraft Java 1.21.11 + Fabric, Java 21.

- Vanilla swing is the default. Custom swing exposes independent rotation axes, offsets, speed, duration, peak timing and easing. Only rendering is changed.
- Correct hand pivots and mirrored settings; custom attacks no longer cause the separate equip dip.
- Pearl Tracer follows only server-confirmed pearls owned by the local player, with a brighter smooth core and bounded histories.
- More player-trail and hit-particle settings. Player trails remain hidden in first person.
- Automatic updates from this repository: checks at startup and every 15 minutes, verifies the release checksum and mod identity, applies after Minecraft closes. Restart to use the new version. One previous jar is kept as a non-loadable .previous backup.

Install this version once, replacing your old PulseVisual jar. Future published releases are automatic unless disabled under General. Fabric API is still required.
